# MATHNEX
Engineering mathematics, computing, materials and fibre-science studio that runs in the browser (React + Vite shell around a self-contained app in `index.html`).

- `npm install && npm run dev` / `npm run build`
- Optional accounts, dashboard, monetization hooks: see **docs/SETUP.md**, **docs/FEATURES.md**, **docs/TESTING_REPORT.md**
- Database: `supabase/migrations/001_mathnex_accounts.sql`
- Platform layer: `public/platform/`, runtime config: `public/config.js`
- Android/Termux notes: `README_ANDROID_TERMUX.md`
